# Release v0.2.4

**Date:** 2026-05-24

## Summary

Safer semantic cache keys for production: multimodal inputs and per-model isolation.

## Highlights

- **Multimodal cache keys** — `content` as a list of blocks (`text`, `image_url`, Anthropic `image`, audio/video) is normalized correctly. Media is fingerprinted with SHA-256 (no full base64 stored in cache).
- **Per-model cache scope** — cache lookups and stores are scoped by the `model` you pass to `complete()` / `stream()`. `gpt-4o` and `gpt-4o-mini` no longer share hits for the same prompt.
- **`Message` type** — `dict[str, Any]` alias for OpenAI-compatible message payloads, including multimodal `WarmupEntry` messages.

## Upgrade notes

- No breaking API changes for typical usage. Cache entries written before 0.2.4 without a `model` field will not match new lookups that pass `model=...`.
- After upgrading, flush Redis/Qdrant caches if you rely on strict model boundaries in existing data.

## Install

```bash
pip install llm-cache-router==0.2.4
```
